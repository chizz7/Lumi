## Key principles to keep in mind when adding code

1. **No LLM calls on the customer hot path.** The modules/audio path → Kokoro/DeepInfra is the only external call at runtime, and it hits the cache first. An LLM may only be called from the authoring-plane scripts in `scripts/author/`, never from any module imported by a route handler or job.

2. **The learning-beat validator in modules/assemble is non-negotiable.** Never catch and suppress its errors. If it fires, the job fails, status='failed', a human investigates.

3. **All parent free text goes through moderate() before anything else.** Do not add a new field that accepts text without wiring it to moderation first.

4. **modules/compliance/deleteAccount() must stay the single source of truth for deletion.** If you add a new bucket or Storage prefix, add its cleanup here.

5. **The worker process is separate from Next.js.** Don't import from jobs/worker.ts in any app/ or lib/ file. Communicate via getBoss().send() only.

## Local development quickstart

```bash
# 1. Clone and install
npm install

# 2. Copy env vars
cp .env.example .env.local
# Fill in: SUPABASE_URL, SUPABASE_ANON_KEY, SUPABASE_SERVICE_ROLE_KEY,
#          DATABASE_URL, DIRECT_URL, DEEPINFRA_API_KEY,
#          STRIPE_SECRET_KEY, STRIPE_WEBHOOK_SECRET, RESEND_API_KEY

# 3. Apply DB schema
npm run db:migrate      # runs prisma migrate dev against DIRECT_URL
npm run db:generate     # generates the Prisma client

# 4. Run the app + worker in parallel
npm run dev             # Next.js on :3000
npm run worker:dev      # pg-boss worker (separate terminal)

# 5. Forward Stripe webhooks locally
stripe listen --forward-to localhost:3000/api/webhooks/stripe
```
